Starte Sanity prosjekt

Fiskum-prosjekt start-guide (Windows)
1️⃣ Åpne terminalen (trykk Windows + S, skriv cmd, trykk Enter).
2️⃣ Gå til prosjektmappen
bash
KopierRediger
cd C:\projects\fiskum

3️⃣ Start hele prosjektet (nettside + Sanity Studio)
bash
KopierRediger
pnpm run dev

Nettside: http://localhost:3000


Sanity Studio: http://localhost:3333



📌 Ekstra
Kun Studio:


bash
KopierRediger
pnpm --filter ./apps/studio dev

Kun Nettsiden:


bash
KopierRediger
pnpm --filter ./apps/web dev


Vil du at jeg lager dette som en .txt-fil som du kan legge i C:\projects\fiskum så den alltid er der når du åpner mappen?
